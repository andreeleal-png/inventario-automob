# Inventário Automob

App de celular para fotografar os carros no inventário das concessionárias Automob. Ele lê a placa e grava a foto com marca d'água (logo, placa, loja, responsável, data, hora e localização) numa planilha e numa pasta do Google Drive.

- **Raiz do repositório:** página instalável (GitHub Pages) com o ícone da Automob. Ela abre o app publicado no Google Apps Script.
- **`apps-script/`:** código do app (`Code.gs` e `Index.html`) e o passo a passo de instalação (`LEIA-ME.md`).
